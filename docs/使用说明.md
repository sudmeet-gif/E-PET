# E-PET 白猫桌宠

双击桌面上的 **E-PET.exe** 即可运行，无需安装 Node.js 或其他开发工具。小猫默认名为“奶糖”，默认不穿衣服。

## 怎么陪小猫

- 单击或右键小猫：打开“小窝”面板。
- 按住小猫拖动：移动位置。
- 双击小猫：摸摸它。休息和睡觉中的小猫不会因此被叫醒。
- 面板可选待机、逗猫、喂食、抓鱼、休息、睡觉。
- 抓鱼由小猫自己进行：低伏观察、探爪、扑抓，随机成功或失败。成功会叼起小鱼并累计抓鱼数量；一次互动有三次尝试，约 18 秒后回到待机。
- 待机每 30 秒随机做一次舔爪、洗脸、打滚、伸懒腰、小扑跳、摇尾巴、左顾右盼、踩奶、打哈欠、举爪撒娇，相邻两次不会重复。
- 休息／睡觉每 30 秒仅触发睡梦伸腰、轻轻翻身、蜷身蹭蹭，随后继续休息／睡觉。

## 小窝设置

可改名（最多 12 个字）、选择无／莓粉针织／晴蓝水手／暖黄毛衣、切换日间／夜间模式、调节音量和静音、调节大小、选择始终置顶、暂停／继续活动。

**开机自启动默认关闭。** 开启后会在登录 Windows 时启动当前桌面的 E-PET.exe；关闭后会取消登记。启用后请保留 EXE 的名称和位置；如移动文件，请从新位置启动后重新关闭、开启此开关。

名称、衣服、外观、音量、大小、位置、休息状态和抓鱼数量会保存。隐藏后，可点击任务栏右侧的小猫托盘图标找回；托盘也可退出。

## 文件和运行方式

- 单个 EXE 包含全部图片和音效，运行时不需要联网。
- 首次运行会自动解压运行组件，稍等片刻即可。
- 设置优先存放在用户应用数据目录的 `WhiteKittenCompanion` 文件夹。该位置不能可靠保存时，程序使用 EXE 旁的隐藏文件夹“白猫桌宠数据”。不要在程序运行时删除设置目录。
- 图片采用 AI 制作的高清关键姿势与短过渡播放；每套穿着包含 36 张 512×512 透明图。喵叫、吃东西、呼噜、水声等为随包原创合成音效。
- 目标平台 Windows x64，本机已在 Windows 11 实测；未逐一验证所有 Windows 版本、多屏和缩放组合。应用未配置个人代码签名证书。

制作参考用户提供的桌宠教程，使用独立实现的 Electron 透明窗口、动作状态和设置模块。没有复用上一个人物的肖像素材。
